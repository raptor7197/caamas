# caamas

a project that's mostly makefile because apparently writing actual code is overrated.

## what is this?

it's a delightful mix of kotlin, c++, and a dash of everything else. 63% makefile means we're either really organized or really confused. probably the latter.

## the breakdown

- **makefile** (63.6%) - the real mvp
- **kotlin** (22.2%) - for when we want to be fancy
- **c++** (5.9%) - legacy energy
- **other stuff** (8.3%) - cmake, python, shell, typescript. we get bored easily.

## getting started

if you can figure out what this does from a makefile, you're already ahead of us.
